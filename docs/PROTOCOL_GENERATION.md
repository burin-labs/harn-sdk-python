## Updating

Only ingest an artifact from a released Harn tag. Copy it into
`src/harn/protocol/`, replace `spec/openapi.yaml` with the exact release spec,
then run `python scripts/normalize_protocol_artifact.py`. That deterministic
step supplies the pinned protocol enum as the default for each protected
operation. It removes repeated call-site boilerplate without changing request
or response types.

Update the expected release values and normalized artifact checksum in
`scripts/check_protocol_artifact.py`, then run:

```sh
python scripts/normalize_protocol_artifact.py
python scripts/check_protocol_artifact.py
python scripts/check_version_sync.py
ruff format --check src tests scripts examples
ruff check src tests scripts examples
pytest -q
python -m build
python -m twine check dist/*
python -m pip install --force-reinstall dist/*.whl
python scripts/check_built_package.py
```

Generated files are excluded from Ruff because the generator owns their
format. The artifact checker proves their checksum, complete 85-operation
projection, and typed sync and async entry points.
